# Guida Steam

`guide.txt` è il corpo della guida, nel markup di Steam. Si apre, si seleziona
tutto, si incolla nell'editor della guida. È un `.txt` e non un `.md` perché
il contenuto non è Markdown: un'anteprima Markdown lo mostrerebbe deformato.

## Campi da compilare a mano

| Campo | Valore |
|---|---|
| Titolo | `Traduzione italiana completa - Complete Italian translation` |
| Descrizione breve | vedi sotto |
| Tipo di guida | Walkthrough, oppure Miscellaneous |
| Lingua | Italiano |
| Visibilità | Pubblica |

Descrizione breve:

    Come installare la traduzione italiana completa del gioco: tutte le 5699 battute, il dizionario, i nomi e le quest. Nessun file del gioco viene modificato.

## Immagine di anteprima

Steam richiede un'immagine per la guida. Basta uno screenshot del gioco in
italiano — meglio se con una battuta di dialogo leggibile, così si capisce a
colpo d'occhio cosa fa il mod. Le guide senza immagine rendono molto meno
nei listati.

## Dopo la pubblicazione

Quando la pagina Nexus viene approvata, aggiungere il link nella sezione
`[h1]Link[/h1]` in fondo.

Il numero di battute compare in tre punti della guida e nella descrizione
breve: aggiornarlo a ogni nuova versione.
